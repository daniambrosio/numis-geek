# Spec 74 — Dashboard de Despesas e despesa mensal média

Status: 📝 Draft

Trilha Despesas: 68 → 69 → 70 → 71 → 72 → 73 → **74** → 75. Depende da 70 (transactions) com dados reais importados via 71.

## Contexto

**A métrica-alvo de toda a trilha**: quanto é a despesa mensal média do user. Decisão da entrevista (2026-08-09):

> Média dos **últimos 12 meses fechados**, excluindo transferências e renda.

Definição precisa:

- Universo: `transaction` com `amount < 0`, cuja categoria (ou categoria-pai) tem `kind = EXPENSE`. Exclui `TRANSFer` (pagamento de fatura, movimentação entre contas próprias) e `INCOME`.
- Tx **sem categoria** contam como despesa quando `amount < 0` (não deixar buraco silencioso), mas o dashboard mostra o % sem categoria como alerta de qualidade.
- Card tx conta no **event_date da parcela** (cada parcela no seu mês — coerente com a decisão de parcelamento da spec 70). O pagamento da fatura em si nunca conta (é TRANSFER).
- Moeda: soma em `amount_brl`; toggle BRL/USD no hero (padrão dual-currency do repo, spec 41).
- "12 meses fechados" = do 1º dia de `mês_atual - 12` até o último dia de `mês_atual - 1`. Mês corrente fica fora da média (parcial), mas aparece no dashboard como "mês em andamento".

## API

`GET /api/expenses/summary` →

```json
{
  "avg_monthly_expense_12m": …, "avg_monthly_income_12m": …,
  "months": [ { "ym": "2026-07", "expense": …, "income": …, "net": …,
                "by_category": [ {"category_id", "name", "color", "total"} ],
                "uncategorized_pct": … } ],   // 13 entradas: 12 fechados + corrente
  "top_categories_12m": […], "top_parties_12m": […]
}
```

Tudo em BRL e USD (mesmo shape `_brl`/`_usd` das telas dual-currency).

## Frontend — página `/despesas` (sidebar: **Despesas**)

Protótipo tem página de budget com actuals por categoria — reaproveitar o layout de tabela categoria × mês, sem a parte de metas (budget fica pra spec futura):

1. **Hero**: Despesa mensal média (12m) — o número canônico — + receita média e resultado médio; toggle BRL/USD.
2. **Gráfico de barras mensal** (13 meses: 12 fechados + corrente destacado como parcial): despesa por mês, linha da média. Usar o padrão de chart do repo (ProventosChart).
3. **Tabela categoria × mês** (estilo budget do protótipo): linhas = categorias top-N + "Outros", colunas = últimos 6/12 meses, célula com valor; coluna final média.
4. **Top parties 12m** — card lateral.
5. Badge de qualidade: "X% sem categoria" com link filtrado pra Movimentações.
