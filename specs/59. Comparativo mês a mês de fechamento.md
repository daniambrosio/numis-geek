# Spec 59 — Comparativo mês a mês de fechamento

## Status: 📝 Draft — entrevista completa 2026-08-01; pronto pra implementar

## Priority

Alta — bloqueia análise mensal do patrimônio. User não tem lugar pra
entender por que abril/26 ficou abaixo de março e maio.

## Why

Hoje o user enxerga só o agregado:

- Lista de Fechamentos mostra patrimônio total (BRL/USD) por período,
  mas não dá pra clicar e ver o que mudou.
- O chart "Evolução" no Dashboard mostra a barra de abril menor que
  vizinhas — sinal claro de mês ruim — mas não tem drilldown.

Falta um lugar que responda "o que aconteceu entre março e abril":
quais classes caíram, quais custodiantes puxaram a queda, quanto foi
BR vs US. MVP não decompõe câmbio×preço×fluxo (fica pra futuro).

## Decisões (entrevista completa)

### Nome
**"Comparativo"** — item top-level no menu lateral.

### Arquitetura de componentes
Dois componentes independentes, reaproveitados em vários entry points:

- **`DiffPanel`** — tabela N-way (2..N colunas de snapshot lado a lado),
  cada linha é uma dimensão (total + breakdowns), cada célula mostra
  valor absoluto + Δ vs coluna de referência.
- **`SeriePanel`** — chart temporal com N meses no eixo X. Multi-linha:
  total + uma linha por classe. Legend interativo (toggle de séries
  ligado/desligado), persistente per user.

### Entry points (3, usam os mesmos componentes)

| # | Onde | DiffPanel | SeriePanel | Cardinalidade default |
|---|------|-----------|------------|-----------------------|
| **A** | Nova seção "Comparativo" no fim de `/fechamento/:ym` (após "Maiores altas/quedas") | ✅ | ✅ | 2 (A = fechamento aberto, B = anterior); "Adicionar coluna" pra virar N-way |
| **B** | Página própria `/fechamentos/compare` (item top-level no menu) | ✅ | ✅ | 2..N livres; N sem teto rígido |
| **C** | Painel expansível abaixo do chart Evolução em `/fechamentos` | ✅ | ✅ | 2 (clica em barra do chart → abre X vs X-1); "Adicionar coluna" pra virar N-way |

A e C são thin wrappers: chamam o mesmo componente que B, apenas
pré-preenchendo o estado inicial (A trava a primeira coluna no
fechamento aberto; C dispara com a barra clicada + anterior).

### Cardinalidade
- **2..N sem teto rígido** em todos os entry points. UX precisa lidar
  com overflow horizontal (tabela scrollable, chart com axis condensado).
- Dropdown de seleção lista **apenas snapshots com status CLOSED** —
  drafts e em revisão não aparecem, pra evitar comparar contra números
  não confirmados.
- Ordem cronológica: **mais antigo à esquerda, mais recente à direita**
  (alinha com o chart Evolução; leitura da esquerda pra direita como
  linha do tempo).

### Cálculo do Δ
Toggle no header do DiffPanel, persistente per user:
- **Encadeado** — cada coluna mostra Δ vs coluna imediatamente anterior.
- **Vs base** — todas as colunas comparadas contra a primeira coluna.

Formato de cada célula: `valor` (linha 1) + `Δ absoluto` / `Δ %` (linha 2).
Primeira coluna nunca mostra Δ.

### Breakdowns (dimensões) no DiffPanel
Sempre visíveis no MVP (não colapsáveis):
- **Total do patrimônio** (linha destacada)
- **Por classe de ativo** (Ações BR, Ações US, FII, RF, Cripto, etc.)
- **Por custodiante** (Avenue, Nubank, Rico, etc.)
- **Por país** (BR / US)

**Top ativos (ganhos/perdas) fica FORA do MVP.** Se o user precisar de
"quem foi o vilão", ele vai pro Fechamento detail. Vira spec futura.

### SeriePanel (chart)
- **Total + linhas por classe** (multi-linha) por padrão.
- Legend com checkbox pra ligar/desligar cada série; seleção persiste
  per user.
- Eixo Y na moeda selecionada (respeita toggle BRL/USD).
- Eixo X mostra os N meses selecionados (rotulados `mmm/aa`).

### Moeda
Toggle BRL/USD persistente per user (compartilha estado com o hero
dual-currency do dashboard — reaproveita o mesmo user setting).

### URL / persistência
- Página B aceita deep-link:
  `/fechamentos/compare?ym=2026-06,2026-05,2026-04&ccy=BRL&base=chained`
- Se abrir sem parâmetros, carrega **último estado persistido do user**
  (últimos meses/moeda/base/séries visíveis).
- URL sempre reflete o estado corrente (útil pra bookmark e pra
  compartilhar em conversas de investigação).

## Escopo Backend

### Endpoint novo

```
GET /api/snapshots/compare?ym=<ym1>,<ym2>,...&currency=<BRL|USD>
```

Retorna array de N snapshots, cada um agregado por dimensão:

```json
{
  "currency": "BRL",
  "snapshots": [
    {
      "ym": "2026-04",
      "period_end": "2026-04-30",
      "fx_rate": 5.12,
      "total": 1382000.00,
      "by_class":       [{"key": "ACOES_BR", "value": 420000}, ...],
      "by_custodian":   [{"key": "Avenue",   "value": 550000}, ...],
      "by_country":     [{"key": "BR",       "value": 780000},
                          {"key": "US",       "value": 602000}]
    },
    { "ym": "2026-05", ... },
    { "ym": "2026-06", ... }
  ]
}
```

- Só aceita `ym` com snapshot em status CLOSED; retorna 400 pra qualquer
  outro.
- Valores já convertidos pra `currency` solicitada usando `fx_rate` do
  próprio snapshot (respeita imutabilidade — ver memory
  `mv_columns_invariant`).
- Δ calculado no **frontend** (mais simples pra suportar toggle
  encadeado↔base sem re-fetch).

### Endpoint auxiliar (dropdown de seleção)

```
GET /api/snapshots/closed
→ [{"ym": "2026-06", "period_end": "2026-06-30", "total_brl": ..., "total_usd": ...}, ...]
```

Já pode existir via listing de snapshots — verificar antes de duplicar.

### Persistência de estado per user

Nova coluna em `user_preferences` (ou tabela análoga existente):
- `compare_last_yms` (json)
- `compare_last_ccy` (str)
- `compare_last_base_mode` (str: `chained` | `vs_base`)
- `compare_serie_hidden_classes` (json) — quais séries do SeriePanel
  o user desligou por último

Se essa tabela não existir, cria migration (`op.batch_alter_table` em
SQLite conforme CLAUDE.md).

- `frontend/src/components/comparativo/MonthPicker.tsx` (dropdown que

### Páginas / integrações
- **Nova rota** `/fechamentos/compare` (`ComparativoPage.tsx`) — usa
  ambos os componentes + seletor N-way + toggles.
- **Nova seção** no fim de `FechamentoDetailPage` — `<Card>` "Comparativo"
  após "Maiores altas/quedas". Sem abas (mantém layout em cascata da
  página). Botão discreto no header "Ver comparativo" que scrolla até a
  seção.
- **Painel expansível** em `FechamentosPage` — quando user clica numa
  barra do chart Evolução, renderiza `DiffPanel` + `SeriePanel` abaixo
  do chart, com contexto do mês clicado.

### Menu
Novo item top-level `"Comparativo"` no menu lateral (ícone `git-compare`
ou similar). Adicionar em `frontend/src/lib/nav.ts` (ou onde os itens do
menu lateral vivem).

### Padrões obrigatórios
- Modal / painel expansível fecha com ESC (memory
  `useEscapeKey` pattern).
- Toggle de moeda / base / séries: `disabled + spinner` durante
  qualquer refetch (memory `feedback_user_feedback_during_long_actions`).
- Erros em toast, nunca `alert`. Nunca redirecionar pra `/login` num
  fetch de dados.

## Nomenclatura (memory `nomenclatura_uniforme`)
- "Fechamento" — não usar "Snapshot" na UI.
- "Comparativo" — item de menu, título de página, aba.
- "Valor total (BRL)" / "Valor total (USD)" — labels de coluna
  (memory `feedback_labels_preco_valor`).
- "Custodiante" (não "Corretora", "Instituição", etc.).

## Out of Scope (MVP)

- **Top ativos (ganhos/perdas)** — vira spec futura.
- **Decomposição câmbio × preço × fluxo** do Δ — MVP mostra só Δ total.
- **Comparação contra benchmarks** (CDI, Ibov, S&P) — spec própria.
- **Export PDF/CSV** do diff.
- **Comparação trimestral/anual agregada** (só mensal por ora).
- **Anotações do user por comparação** (tipo "por que abril foi ruim").
- **Alertas automáticos** de variação anômala — coberto pela spec 62.
